# 🛍️ Skin Care & Cosmetics Store

A full-stack e-commerce project for displaying and selling skin care, hair care, and cosmetics products. This project features a modern user interface, a dynamic shopping cart, and a custom database structure.

## ✨ Features

- 🛒 **Dynamic Shopping Cart:** Seamlessly add products to the cart without rendering conflicts or errors.
- 🗂️ **Product Categorization:** Filter and display products across various categories (Skin, Hair, Cosmetics).
- ⚡ **Offline & Fast:** Fully local assets (images and fonts) are used to prevent network timeout errors and significantly boost loading speeds.
- 🇮🇷 **RTL Support & Localization:** Uses the standard **Vazirmatn** font and Right-to-Left (RTL) design, perfectly suited for Persian-speaking users.
- 💾 **Relational Database:** Product details and pricing are dynamically managed via a MySQL database.

## 🛠️ Technologies Used

* **Frontend:** React.js, CSS
* **Backend:** PHP
* **Database:** MySQL (via XAMPP)

## 🚀 Installation and Setup

Follow these steps to run the project on your local machine:

### 1. Prerequisites
* Install [XAMPP](https://www.apachefriends.org/index.html) to run the local server (Apache and MySQL).
* Install [Node.js](https://nodejs.org/) to run the React frontend.

### 2. Database Setup
1. Open XAMPP and **Start** both **Apache** and **MySQL**.
2. Go to `http://localhost/phpmyadmin` in your browser.
3. Create a new database (e.g., `skin_care_db`).

---

## 📂 Static Files Structure

Ensure your local static files are placed in the correct directories within the `public` folder:
* **Images:** `frontend/public/images/` (e.g., `hydra.jpg`, `serum.jpg`, etc.)
* **Fonts:** `frontend/public/fonts/` (contains `Vazirmatn-Regular.woff2`)
